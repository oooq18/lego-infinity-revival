## 关于《乐高®无限》

《乐高®无限》(Lego Infinite) 是由乐高集团正版授权、腾讯NEXT Studio自研的首款平台型3D沙盒游戏。

- **开发商**：腾讯NEXT Studio
- **发行商**：腾讯游戏
- **游戏类型**：3D沙盒 / UGC创作
- **预约开启**：2018年9月19日
- **正式上线**：2019年8月8日
- **停运时间**：2022年8月31日 12:00（共创测试结束）
